# 2-Minute Advance Candle Signal Bot (Android/Termux)

This is a demo/paper-trading signal app. It does NOT log into Quotex or place real-money trades.

## Termux quick start
1. Install Termux and Termux:API if needed.
2. Install Python:
   `pkg update && pkg install python git`
3. Run the console version:
   `python bot.py`
4. Enter candle OHLC values when prompted.

## APK
The Android project is intentionally minimal. Build it with Android Studio/Gradle on a computer, or adapt it for your Android build environment.

Signal logic is educational and not guaranteed to predict market direction.
